# Security policy

This repository is the generated GitHub Marketplace distribution of the `noru-review` action.
The code is maintained in [noru-tech/noru-grc-engineering](https://github.com/noru-tech/noru-grc-engineering), path `.github/actions/noru-review`, and
every release overwrites this tree.

## Reporting a vulnerability

Report it privately through GitHub private vulnerability reporting on the source
repository: <https://github.com/noru-tech/noru-grc-engineering/security/advisories/new>. Do not open a public issue for an unfixed
vulnerability, here or upstream.

The full policy, including supported versions, response times and the threat model, is
[SECURITY.md in the source repository](https://github.com/noru-tech/noru-grc-engineering/blob/main/SECURITY.md).
